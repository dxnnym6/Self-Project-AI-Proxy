# AI Proxy Project
A proxy for local LLM interactions that is designed to prevent prompt injection and unauthorized model behavior

# Phase 1
Successfully bridged Python with a local Ollama instance (Llama 3.1) and implemented system-level hardening to prevent identity hallucination.

# Setup
## Setup 1. Clone the repo: `git clone https://github.com/your-username/sentinel-ai-proxy.git`
2. Ensure Ollama is running locally.
3. Install dependencies: `pip install -r requirements.txt`
4. Run the proxy: `python hello_ai.py`
